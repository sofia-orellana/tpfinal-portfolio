# Portfolio personal — Sofia Orellana
- **Sitio:** https://tpfinal-portfolio.netlify.app/ · **Figma:** https://www.figma.com/design/iGww3VcM4solEnYjLK4CSu/Portfolio-personal-%E2%80%94-Sofia-Orellana?node-id=0-1&p=f&t=KMYiJ0lA8fn70mWy-0
- **Stack:** HTML5 + CSS3 (variables `:root`) y JavaScript vanilla (menú y modal). Sin frameworks.
- **Fuentes y recursos:** Inter y Lora (Google Fonts). Paleta propia (Realtime Colors). Sin templates.
- **Uso de IA:** estructura inicial de HTML/CSS generada con Claude a partir de capturas del Figma; revisada y ajustada por la autora.
- **Deploy:** GitHub Pages → Settings → Pages → rama `main`, carpeta raíz.
- **Capturas:** Lighthouse mobile y comparación Figma / sitio.
